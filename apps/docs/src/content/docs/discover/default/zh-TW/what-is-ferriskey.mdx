# 什麼是FerrisKey？

FerrisKey 是一個用 Rust 編寫的開源身分與存取管理（IAM）系統。它處理您應用程式的認證、授權和使用者管理，而不會帶來舊IAM平臺的運營負擔。

<span id="what-is-iam" />

## 什麼是 IAM？

身分與存取管理回答系統收到的每個請求的兩個問題：

- **認證**：你是誰？透過密碼、多因素挑戰、通行金鑰或聯合提供者進行驗證。
- **授權**：你被允許做什麼？經過身分認證的身分可以存取哪些資源和操作。

在這兩者之上，IAM 系統會簽發和驗證 JWT，使用單點登入將應用程式繫結在一起，跟蹤會話，記錄審計日誌，並與外部身分提供商通訊。

<span id="why-ferriskey" />

## 為什麼選擇 FerrisKey？

FerrisKey 是從零開始為那些希望擁有可以實際閱讀和理解的 IAM 的團隊而編寫的。

- **Rust 基礎**：記憶體安全和可預測的效能，貫穿非同步 I/O。
- **多租戶**：身分域隔離使用者、客戶端、角色、憑據和配置，因此一次部署可以服務多個組織。
- **模組化**：產品被拆分為專注的模組。只開啟你需要的模組。
- **開源**：採用 Apache-2.0 許可證，在公開環境中開發。

## 模組

每個模組負責身分管理的一部分。

:::
:::card{label="SeaWatch" icon="lucide:eye" href="/zh-TW/modules/seawatch/overview"}
對跨您的身分域的關鍵操作進行審計和安全事件管理。
:::
:::card{label="Compass" icon="lucide:compass" href="/zh-TW/modules/compass/overview"}
用於多步驟登入的認證流程記錄和除錯。
:::
:::card{label="Abyss" icon="lucide:link" href="/zh-TW/modules/abyss/overview"}

:::

針對生命週期事件和外部通知的事件驅動整合。
:::
:::card{label="組織" icon="lucide:building-2" href="/zh-TW/modules/organization/overview"}
