## 模块是如何构建的

一个模块可以作为 `core/src/domain/` 下的领域模块存在，接近核心，或者当它值得单独测试和版本控制时，作为 `libs/` 下的独立 crate 存在。有几个模块正在从第一种形式迁移到第二种形式。

无论哪种方式，其结构都是相同的，并遵循六边形架构：业务逻辑是纯粹的，其依赖通过端口引入，而基础设施位于边界上。`ferriskey-api-*` crate 承载已经被拆分的模块的 HTTP 层。
