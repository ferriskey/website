## 模組是如何構建的

一個模組可以作為 `core/src/domain/` 下的領域模組存在，接近核心，或者當它值得單獨測試和版本控制時，作為 `libs/` 下的獨立 crate 存在。有幾個模組正在從第一種形式遷移到第二種形式。

無論哪種方式，其結構都是相同的，並遵循六邊形架構：業務邏輯是純粹的，其依賴透過埠引入，而基礎設施位於邊界上。`ferriskey-api-*` crate 承載已經被拆分的模組的 HTTP 層。
