# `logout`

Remove the session saved by [`login`](/en/cli/commands/login). It deletes `credentials.toml`, so the next command falls back to client credentials (if the context has a secret) or asks you to log in again.

```bash
ferris-ctl logout
```

The command takes no arguments and makes no network call. It reports whether a session was removed:

- `Logged out. Stored credentials removed.` when a session existed.
- `No active session; nothing to remove.` when there was nothing to delete.

The message is plain text whatever `-o` says. Your contexts and stored sources stay in `config.toml`.

`logout` only deletes the local file. It sends nothing to the server, so the session and its tokens are not revoked there.

See [Authentication](/en/cli/authentication) for how sessions are stored and refreshed.
