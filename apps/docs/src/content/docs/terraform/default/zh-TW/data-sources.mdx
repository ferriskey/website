# 資料來源

資料來源讀取 Terraform 不管理的物件，如`master`身分域或 FerrisKey 自行建立的角色。

## ferriskey_realm

```hcl
data "ferriskey_realm" "master" {
  name = "master"
}

output "access_token_lifetime" {
  value = data.ferriskey_realm.master.settings.access_token_lifetime
}
```

取`name`並返回`realm_id`、`created_at`、`updated_at`和`settings`，這些都是`ferriskey_realm_settings`管理的[身分域設定](/zh-TW/discover/core-concepts/realms#realm-settings)。

## ferriskey_role

```hcl
data "ferriskey_role" "realm_admin" {
  realm = "master"
  name  = "master-realm"
}

resource "ferriskey_user_role" "runner_realm_admin" {
  realm   = "master"
  user_id = ferriskey_client.terraform_runner.service_account_user_id
  role_id = data.ferriskey_role.realm_admin.id
}
```

按`realm`和`name`查詢角色，返回其UUID，分別為`id`、`description`和`permissions`。用它來分配FerrisKey建立的角色，比如[bootstrap](/zh-TW/terraform/getting-started)中的`master-realm`，或者其他狀態管理的角色。

## ferriskey_openid_configuration

```hcl
data "ferriskey_openid_configuration" "acme" {
  realm = "acme"
}

output "token_endpoint" {
  value = data.ferriskey_openid_configuration.acme.token_endpoint
}
```

讀取身分域的[發現文件](/zh-TW/discover/core-concepts/authentication#openid-connect-discovery)，無需身分認證。它返回 `issuer`、`authorization_endpoint`、`token_endpoint`、`userinfo_endpoint`、`jwks_uri`、`introspection_endpoint`、`revocation_endpoint`、`end_session_endpoint`、`grant_types_supported` 和 `token_endpoint_auth_methods_supported`。

將這些值傳遞給您在同一次執行中配置的應用程式，例如作為 Kubernetes 部署的環境變數，而不是手動構建 URL。
